## Tethwork 0.0.1 beta — build 5

> **Синхронизация iCloud заблокирована.** iCloud Drive и другие облачные папки
> нельзя использовать как корни синхронизации, включая ранее сохранённые
> подключения. Реестр файлов не снимает эту блокировку.
>
> **iCloud synchronization is blocked.** iCloud Drive and other cloud-managed
> folders cannot be used as sync roots, including saved connections. The file
> inventory does not enable iCloud synchronization.

### Changes / Изменения

- Persistent diagnostic inventory of expected local paths for each connection:
  sizes, modification times, file IDs, confirmations and pre-sync missing-file
  observations. Stored separately from the application and sync roots in
  `~/Library/Application Support/Tethwork/LocalInventory`.
- Settings button to open the inventory folder. The inventory records metadata,
  not document contents, and never restores or deletes user files. It is not a
  backup and cannot reconstruct incidents predating its installation or identify
  which external program removed a file.
- Automatic pruning of unselected local files has been removed. Changing or
  reloading selections is not permission to evict local copies. Explicit
  **Keep Online Only**, Trash and normal two-way reconciliation remain separate
  operations and can still remove files in supported non-cloud roots.
- The entire Dock icon is 6% smaller, preserving its proportions.
- Developer ID signed, Apple-notarized universal application for Apple Silicon
  and Intel; macOS 14 or later.

### Safety / Безопасность

**Бета-версия: перед использованием сделайте независимую резервную копию.**
Синхронизация может перезаписывать и удалять файлы на Mac и сетевом диске.
Реестр и встроенная корзина не заменяют резервную копию. Причина ранее
сообщённого исчезновения файлов после переустановки не установлена.

**Beta software: keep independent, tested backups before use.** Synchronization
can overwrite or delete files on the Mac and network volume. The inventory and
built-in Trash are not backups. The cause of the previously reported file loss
after reinstalling has not been established.

This release is available for manual download only. The Sparkle update feed is
unchanged and contains no downloadable update.
